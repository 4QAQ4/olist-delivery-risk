## 商品明细表聚合检查（第 3 天）

### 1. 聚合目的

原始 `olist_order_items_dataset.csv` 每行代表一条商品明细，一笔订单可以对应多条明细。

为了后续与订单表关联，按照 `order_id` 分组，生成一行对应一笔订单的汇总表。

### 2. 数据检查结果

| 检查项目 | 结果 |
|---|---|
| 原始商品明细数量 | 112650 |
| 不同订单数量 | 98666 |
| 商品价格负数数量 | 0 |
| 商品价格零值数量 | 0 |
| 运费负数数量 | 0 |
| 运费零值数量 | 383 |
| 订单明细组合键重复数量 | 0 |
| 聚合后订单重复数量 | 0 |

运费为零的记录暂时保留，不直接视为异常。

### 3. 聚合字段

- `item_count`：商品明细数量
- `product_amount`：商品金额总和
- `freight_amount`：运费总和
- `total_amount`：商品金额与运费之和

### 4. 聚合结果验证

- 订单数量一致性：通过
- 订单编号唯一性：通过
- 商品明细数量一致性：通过
- 商品金额一致性：通过
- 运费金额一致性：通过（以最终重新运行的结果为准）

### 5. 输出文件

`data/processed/order_items_agg.csv`

用于后续订单表、客户表的关联分析。
